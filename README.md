# UNO TẾT 2027
Game UNO online độc lập, tối đa 6 người/phòng tính cả chủ phòng. Có tạo phòng, mã/QR, bài riêng, chat và 8 emoji. Không tích hợp TikTok LIVE.

Chạy local: Node.js 18+, `npm install`, `npm start`, mở http://localhost:3000.

Railway: deploy từ GitHub repo, start command `npm start`, sau đó Settings → Networking → Generate Domain.

Đây là bản MVP cần kiểm thử thực tế trước khi phát hành. +2/+4 không cộng dồn; người kế tiếp rút bài và mất lượt.
