UNO card image assets — GitHub filename convention

Color cards:
blue-0.png ... blue-9.png
blue-draw2.png, blue-reverse.png, blue-skip.png
Same naming for green, red, and yellow.

Wild cards:
wild-wild.png
wild-draw4.png

One PNG per card face/type. The game logic should create duplicate card instances in the deck as required by classic UNO rules.
Duplicate wild artwork files are also included with -2, -3, -4 suffixes for convenience.
